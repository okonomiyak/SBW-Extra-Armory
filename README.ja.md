# SBW Extra Armory (sbwarmory)

[English README](README.md)

Minecraft 1.20.1 / Forge 47.x 向けの[SuperbWarfare](https://www.curseforge.com/minecraft/mc-mods/superb-warfare)アドオン。変わった挙動の擲弾、グレネードランチャー、投げナイフ、手動誘導ミサイルランチャー、巡航ミサイル要請システム、暗視ヘルメット、建築ブロックなどを追加する。

## 必要な環境

- Minecraft 1.20.1, Forge 47.x
- [SuperbWarfare](https://www.curseforge.com/minecraft/mc-mods/superb-warfare) 0.8.9.1以上
- [GeckoLib](https://www.curseforge.com/minecraft/mc-mods/geckolib) 4.4以上(SuperbWarfare自体が要求するので別途入れる必要はほぼない)

## アイテム一覧

全アイテムは専用の**SBW Extra Armory**クリエイティブタブにまとまっている。

### 擲弾・投擲武器

| アイテム | 説明 |
|---|---|
| **クラスター擲弾** | 着弾約8tick前を検知して起爆前に3発の子爆弾に分裂する40mmグレネード。ランチャー専用の弾薬版(手投げ不可)もある。 |
| **スモーククラスター擲弾** | 同じ分裂挙動だが、子弾がM18発煙弾になっている。こちらも弾薬版あり。 |
| **スプリンググレネード** | 構えて離すと投げる手榴弾。起爆直前に1.5ブロック真上に跳ねる、Sマイン方式。 |
| **投げナイフ** | SuperbWarfareの汎用弾エンティティを使った投擲武器で、ヘッドショット倍率もそのまま適用される。重力無視でまっすぐ飛ぶ。 |

### 銃火器

| アイテム | 説明 |
|---|---|
| **グレネードランチャー** | 通常のライフル弾と、クラスター擲弾を発射するアンダースラング「グレネード」枠、2種類の弾薬を持つライフル型武器。 |
| **SRAW / SRAWミサイル** | 肩撃ち式ランチャー。ミサイルは*ワイヤー誘導*式で、発射角度だけでなく飛行中毎tick撃った本人の視線方向へ曲がっていく。 |

### 要請システム

| アイテム | 説明 |
|---|---|
| **巡航ミサイル指示機** | 右クリックで覗き込み照準(望遠鏡風スコープ演出、スクロールでズーム)、左クリック長押しで着弾地点に巡航ミサイルを要請する。ミサイルは数秒間上空に隠れて待機(空襲サイレンが周囲に鳴り響く)した後落下し、設定可能な範囲にダメージを与える。使用すると消費される。 |
| **野獣ミサイル指示機** | 同じ要請システムのネタ版。「サイレン」はSuperbWarfare本体のsenpai(モブ)の唸り声、着弾まで2倍の時間がかかり、着弾時はキノコ雲の代わりに岩の欠片が飛び散りコミカルなボイスが鳴る。 |

巡航ミサイル関連のバランス(ダメージ・範囲・タイミング・サイレン音量)は`config/sbwarmory-server.toml`でサーバー側から設定可能。

### 頭防具

| アイテム | 説明 |
|---|---|
| **暗視ゴーグル**(青/赤) | 専用3Dモデル付きの本物のヘルメット防具。装備中は暗視効果を継続付与。**Nキー**で暗視効果と一人称専用の緑シェーダーだけをON/OFFできる(脱がなくてよい)。 |
| **ヘルメット**(青/赤) | ゴーグルや効果のない、同じ被り物モデルの見た目だけ版。 |

### ブロック

| アイテム | 説明 |
|---|---|
| **コンクリートバリア** | ジャージー型防護壁。単体で置くと太い土台形、その上に積むと細い直線壁として継ぎ足される。設置方向に追従し、下のブロックを壊すと自動で土台形に戻る。 |
| **コンクリートブロック** | 同じ風化コンクリートテクスチャを使った普通の立方体ブロック。 |

## ビルド方法

```
./gradlew build
```

JDK 21がツールチェーンから使える必要がある。実行構成: `./gradlew runClient` / `./gradlew runServer`。

**リソースだけの変更**(Java抜きのJSON/テクスチャ)は`./gradlew processResources`を明示的に実行すること — `compileJava`だけでは`build/resources`へ再コピーされない。

## 既知の問題

- SRAWランチャーのモデルが、GeckoLibの`GeoModel.getAnimation`で`NullPointerException`(アニメーションリソースが`null`に解決される)により描画時に稀にクラッシュすることがある。発生条件は未特定で、原因調査は継続中。
